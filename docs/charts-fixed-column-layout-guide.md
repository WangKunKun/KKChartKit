# 固定柱宽、间距与滚动窗口

Column 与 Bar 共用 `CartesianChartTheme.columnSpacing`，单位为 UIKit pt，不是比例或物理像素。

```swift
var theme = CartesianChartTheme()
theme.columnSpacing = CartesianColumnSpacing(
    columnWidth: 12, // 柱宽；Bar 对应条形厚度
    inner: 4,        // 同一点内，多系列柱体之间的间距
    group: 16       // 相邻两个点的柱组之间的间距
)
chart.configure(model: model, theme: theme)
```

固定模式优先于 `columnWidthRatio`、`columnInnerSpacingRatio`、`columnGroupSpacingRatio`。设置 `columnSpacing = nil` 恢复原有布局；未使用新配置的接入保持兼容。间距以柱体几何外框为准，不包含描边外扩或阴影。

## 超出一屏：滚动原始数据

固定柱宽时，图表按实际绘图区计算类目窗口，默认显示最早数据。Column 横向拖动，Bar 纵向拖动；不要求额外打开 `isZoomEnabled`。这个开关仍控制捏合缩放，固定尺寸滚动独立启用。

例如每点 3 个可见系列，柱宽 12、组内间距 4、组间距 16：

```text
每点槽宽 = 3 × 12 + 2 × 4 + 16 = 60 pt
300 pt 绘图区可完整显示 5 个点
```

屏幕边缘允许部分可见的柱组，拖动后继续显示。数据不足一屏时，轴线按实际内容长度收短，从起始侧对齐，不把柱宽或间距拉大来填满屏幕。隐藏系列会按剩余可见系列重新计算容量；堆叠视为每点一根柱，忽略组内间距。

固定尺寸的原始模式只平移类目窗口，捏合不会放大柱宽或间距；值轴的缩放仍服从现有配置。滚动在数据边界钳制，不产生类目轴橡皮筋越界。若单组本身比绘图区还宽，可以滚动查看组内剩余部分。

## 手动设置区间

UIKit 继续使用原始索引（从 0 开始，右端不包含）：

```swift
chart.showCategoryRange(100..<120)
```

固定尺寸下，此调用定位区间起点，实际一屏可见数量由空间决定，不能强行同时显示 20 个点。靠近数据末尾时，窗口向前收回，避免末尾留下大块空白。它是定位命令，不限制后续滚动范围。需要只允许浏览指定区间时，应另行提供对应数据子集。

SwiftUI 的柱状图可直接传已有参数：

```swift
ColumnChart(model: model, theme: theme, visibleCategoryRange: 100..<120)
```

更新默认保留窗口；`configure` 或 `resetViewport()` 回到最早数据。`resetViewport()` 在下一次布局生效；需要同步读几何时先 `layoutIfNeeded()`。

## 与高密度聚合配合

未启用聚合时不删除、不平均原始数据，按窗口滚动查看。启用 Column 时间聚合时，按固定柱宽、组内间距、组间距一起计算容量，再选择时间粒度；每个系列仍使用自己的 reducer。

显式固定柱宽优先于 `minimumColumnWidth`。聚合模式可通过区间定位或捏合切换粒度，柱宽保持不变。末尾不足一个时间桶时仍预留完整柱组槽位，仅扩展几何占位；原始数组、真实采样数量、区间结束时间与命中元数据不补点。

Bar 暂无自动时间聚合，使用固定厚度的纵向滚动。未满足时间聚合条件的 Column（例如未配置 reducer）也回退到原始数据滚动。

## 只固定间距

```swift
theme.columnSpacing = .init(inner: 4, group: 16) // columnWidth 为 nil
```

此时柱宽由每个类目槽的剩余空间平均分配，缩放后柱宽会改变，间距保持不变。若间距已经占满槽位，该组不绘制且不产生柱体命中 frame；放大、减少可见类目或启用时间聚合后恢复。需要密集原始数据直接可读时，建议同时指定固定柱宽。

`inner/group` 的负数或非有限值按 0 处理；无效的 `columnWidth`（非有限值或非正数）按自动宽度处理。纯配置可先构造，更新图表仍须在主线程执行。
