## 结论与范围

这次审计针对首页 **折线图** 的实时属性面板、预设切换、实际图表渲染和命中交互，同时回归共用面板的柱状图、条形图和混合图。问题分为三类：

1. **真实错误**：场景残留配置、字体回退、共享弹窗绕过开关/吞掉外部回调、折线弹窗缺少表头 key、手动数据与时间间隔不一致等。已修复并增加回归测试。
2. **设计上的覆盖/前置条件**：系列覆盖全局主题、颜色分区覆盖负值色、刻度位置覆盖间隔/数量等。保留 SDK 语义，在面板中禁用当前不生效的项并说明恢复方法，不再让用户盲试。
3. **保留的渲染边界**：可共享堆叠底边的切线/样式不一致已在后续修复；无共同前层路径的正负/缺测过渡区间采用直线连接，仍不保证全域无缝，见文末“已知限制”。

面板清单来自实际控件登记表，而不是手工猜测：**228 个独立可编辑项**，按“分组 + 标签”去重，覆盖默认、可选配置展开、缺测时长模式、空渐变四种面板形态。预设/局部重置按钮共 16 个，单独统计，不计入 228 项；页面搜索框也不属于图表配置，整数输入框内部的“应用”是该字段的提交操作，不单独统计。

## 如何使用整理后的面板

1. 首页进入“折线图”。搜索框固定在预览及操作按钮下方，不随属性列表滚走；输入分组名或属性名即可筛选，键盘搜索键收起键盘。
2. 搜索 **当前状态**，查看生成数据/手动覆盖系列数量、实际最长点数、可见系列数及优先级说明。
3. 搜索 **编辑系列序号**，先确认当前编辑的是哪条系列，再改逐系列配置；系列序号从 0 开始。全局主题不会覆盖已经明确配置的系列属性。
4. 灰色控件下面会显示原因。按提示启用前置条件或恢复“继承/跟随默认”即可；**暂时禁用不会清空原值**。
5. 所有“场景”按钮先恢复默认配置再加载示例，避免上一个场景的手动数据、曲线、双轴、颜色或弹窗模式污染下一个场景。搜索词保留，方便连点切换。注意：这是有意的完整重置，会替换当前调试配置。
6. 普通属性编辑和“更新样本数据”不做全局重置。“恢复默认配置”重置全部并清空搜索；“重置当前系列样式覆盖”只清空 `style`，不会清空该系列的数据、分区、缺测策略等字段。
7. 命中读数默认最多显示三行；点击“展开读数”可以查看完整原值、绘制值、业务组、索引及位置回调坐标，“收起读数”恢复紧凑显示。
8. “总览 / 最近24点”只调整视口；“重播动画”重播入场动画。属性更新是否保留视口由同名开关控制，场景按钮则重新开始。

### 常见操作示例

- **调全局线宽但没有变化**：确认当前可见系列没有“自定义系列线宽”。关闭该覆盖，或使用“重置当前系列样式覆盖”，再修改主题 `lineWidth`。
- **调负值颜色没有变化**：关闭该系列的 `颜色分区 zones`。显式分区优先，负值颜色并不是第二套叠加效果。
- **调跨空值连线没有变化**：把“缺测策略 autoGap”改为“跟随跨空值连线”；或直接用“全部断开/全部连接/按空点数量/按缺测时长”。
- **测试 11/12/13 连续空点**：搜索 `autoGap` 加载预设，再搜索“缺测”。按时长计算时需要开启时间轴；预设是 300 秒/点。
- **打开面积**：启用主题 `showsArea` 或逐系列“系列面积填充”；随后调整透明度和渐变。分区面积渐变启用时，其颜色优先于系列和全局渐变。
- **测试高密度**：搜索“3000 点尖峰”加载预设。非堆叠且所有可见系列均为直线才具备 Min/Max 准入条件；还需当前视口达到密度门槛才实际降采样。点击图表仍返回原始采样点；点“最近24点”查看明细。
- **自定义值轴刻度**：先设置固定值域，再设置固定间隔；如果“刻度位置”存在有效数值，它的优先级更高。清空刻度位置才能恢复间隔/数量。
- **测试内置弹窗**：选“内置”并打开“容器弹窗”，表头可输入 `时刻 {key}`。“位置回调”只报告命中位置，不显示容器弹窗；“自定义内容”使用 Demo 的 UILabel 预设，不使用内置数值模板。

## 发现的问题与处理

| 问题 | 根因 / 原表现 | 当前处理 |
| --- | --- | --- |
| 场景切换相互污染 | 预设只覆盖一部分状态，旧 `dataText`、系列样式、轴和回调模式仍有效；“3000 点”可能仍绘制旧的几个手动点 | 所有场景统一从默认状态开始；144 组有序场景切换检查数据和配置 |
| 字体选择不可靠 | 使用 `.SFUI-*` 内部字体名称重新构造 UIFont，会回退到错误字体 | 使用公开系统字体工厂及已保存的 UIFont；调字号保留字体类型；保留非预设的当前字体选项 |
| 弹窗两个开关彼此覆盖 | 主题和容器各有一个开关，自定义内容链路又不受 Demo 开关约束 | 面板只保留“容器弹窗”总开关，同步主题与容器；关闭时不安装 Demo 自定义内容 provider |
| 共享提示关闭后仍出现 | SDK 共享提示链路没有检查容器和主题的弹窗开关 | 同时检查两层开关；关闭仍保留命中/准线语义，但隐藏内置弹窗 |
| 共享提示吞掉自定义内容/位置回调 | 共享命中提前消费事件，而外部链路只接受单点 context | 外部 provider 或位置回调存在时回到单点链路；Demo 也明确禁用非内置模式的共享提示项 |
| 位置回调有数据但看不到坐标 | 读数被固定三行截断，坐标在后面的行中 | 多行读数支持展开/收起，UI 测试检查两种状态并保存完整截图 |
| 折线表头 `{key}` 不生效 | `LineHitTarget.tooltipHeaderKey` 恒为 nil | 直接命中、吸附命中、降采样原始点命中都携带类目/时间标签；新增参数默认 nil，兼容旧构造调用 |
| 一天均分间隔与实际数据不符 | 使用“生成点数”计算间隔，但手动数据覆盖可能有不同长度 | 按实际最长系列的点数均分一天；状态显示实际点数 |
| 无效刻度文本导致刻度消失 | 无有效输入时生成空数组而非恢复自动 | 过滤非有限值、去重排序；无有效值返回 nil，恢复自动/低优先级配置 |
| 值域下界大于上界时异常窄 | 原来只强行抬高上界，没有反映用户给出的两个边界 | 交换上下界；相等时扩展 0.001，并展示生效范围 |
| 关闭双轴后参考线/色带消失 | 参考元素仍绑定不存在的次轴 | Demo 的有效配置回到主轴 0，保留用户选择；重开双轴恢复原选择 |
| 降采样状态提示与渲染不一致 | 仅观察主题连线类型，遗漏逐系列覆盖、分组堆叠 | 与 renderer 共用准入判断，并区分“配置可用”与“实际达到密度门槛” |
| 小步长读数误导 / 最小可见类目无效值 | 0.05 步长只显示一位小数；面板允许 SDK 会钳制的 1 个可见类目 | 小于 0.1 的步长显示两位小数；最小可见类目范围统一为 2...30 |
| 混合图预设编辑到了柱体的线样式 | “两组堆叠与目标线”默认编辑首条柱系列，线宽改动没有视觉效果 | 预设选择目标线系列；柱系列不适用的折线配置给出禁用原因 |

## 依赖与优先级速查

这里的“覆盖”不是必须删除某个设置：关闭高优先级覆盖后，原来的低优先级配置继续有效。

| 配置 | 生效规则 / 前置条件 |
| --- | --- |
| 生成点数、正负混合、包含缺测、尖峰、更新样本 | 只影响没有 `数据覆盖` 的系列；所有系列都有手动数据时相应生成控件禁用 |
| 每系列样式与全局样式 | `series.style` > 图形 `kind` 的预设语义 > 全局主题；单纯折线图不开放混合图 kind 选择 |
| 系列颜色 / 主题 seriesColor | 显式系列色优先；Demo 默认给各系列配色，所以默认修改全局色不会改变这些系列 |
| 缺测连接 | 显式 `gapPolicy` > `connectNulls`；时长策略要求有效时间轴，无时间轴时按断开处理 |
| 分区、负值色、标记色 | 显式 zones > 负值色/系列色；显式 `pointColor` 对标记优先，不能改线色 |
| 面积渐变 | 分区渐变 > 系列渐变 > 主题渐变；系列空数组 `[]` 表示使用系列默认渐变，而 nil 表示继承；需要先显示面积 |
| 线标记 | 有效 `showsPoints` 开启后，半径/形状/颜色才可见；空心内径为 0 时没有内芯；密集降采样还可能隐藏标记 |
| 数据标签 | 每系列显示/格式覆盖全局；超过 `dataLabelMaxMarkCount` 或启用密集隐藏时不显示，0 表示全部隐藏 |
| 堆叠 | `stackID` 在启用堆叠且系列参与时有效；业务 `groupID` 不是数学堆叠分组；固定基准/序号数量只用于对应模式 |
| 双轴 | 系列/参考线/色带的次轴选择需开启次值轴；关闭保留选择但按主轴绘制 |
| 值轴刻度 | 有效显式位置 > 固定值域下的固定间隔 > 目标刻度数；刻度数不保证精确数量，域外刻度不显示 |
| 时间轴 | 显式类目标签覆盖时间标签显示，但不取消时间轴的缺测时长计算；一天均分覆盖手动秒间隔 |
| Min/Max | 非堆叠、非序号分组、所有可见系列为直线；目标点数模式优先于宽度/启动门槛且保护各段端点/极值，宽度模式才检查可见密度；隐藏的曲线不阻止其它系列采样 |
| 图例 | 总开关/系列加入图例控制显示；展开完整图例时不用行数/高度上限；最大宽度只用于左右图例；追加高度只用于上下图例 |
| 参考线/色带 | 各自启用后使用子项；色带起止反向时交换，相等时无面积 |
| 缩放与准线 | 缩放参数依赖缩放开关；准线样式依赖准线开关，准线与弹窗不是同一个开关 |
| 弹窗 | “内置 / 自定义内容 / 位置回调”互斥；共享文本与全局模板只用于内置模式；逐系列数值格式覆盖全局后缀和小数位 |
| 弹窗外观 | 关闭弹窗或使用位置回调时不绘制；箭头尺寸依赖 `showsArrow`；Demo 自定义内容的字体/文字色也跟随外观主题 |

- `Charts/SwiftUI/CartesianDemoSettings.swift`、`DemoPropertyControls.swift`、`DemoChartHost.swift`、`ChartDemoPanel.swift`：输入归一化、字体、弹窗与控件显示。
- `Charts/Core/HYMChartView.swift`：共享提示遵守开关及外部回调优先级。
- `Charts/Line/LineChartRenderer.swift`：统一采样准入与命中表头标签。
- `SwiftFunctionProjectTests/LineDemoAuditTests.swift`、`SwiftFunctionProjectUITests/ChartDemoUITests.swift`：回归和清单来源。

以上 `Charts/` 路径位于应用源码目录 `SwiftFunctionProject/` 下。SDK 保持 UIKit 实现，不引入 SwiftUI 依赖；新拆出的状态/依赖类型仅属于 Demo。

## 已知限制与后续工作

**共享底边区间已修复，无共同底边的过渡区间仍有边界。** 后续改为逐区间复用前层原路径，避免截取点列重算切线，以及某个区间换源导致整段回退样式。规则、最小复现与精确几何断言见 [堆叠面积接缝指南](charts-stacked-area-seams-guide.md)。

正负切换、不同缺测策略或独立插值仍可能使某个区间不存在共同连续边界。该区间直连原始基准点，不擅自改变累计值、补点或改动上边界，不保证所有区域无交叉/重叠/空隙。Demo 保留明确提示，不能把“750 组合通过”当作全域像素级正确的证明。

其余测试通过仅说明本次列出的环境、数据和断言范围内没有复现错误，不构成所有配置或平台均无 bug 的保证。
