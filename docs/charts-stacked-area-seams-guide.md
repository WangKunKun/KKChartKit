# 堆叠面积接缝：路径复用与过渡规则

## 2026-10-02：新增严格正负分链模式

G1 受限组合现有显式解决方案：`.diverging` 在渲染层按真实过零分片、共享正负边界，并对同组缺测统一断段；支持混合线型和非面积贡献。自动百分比从原始贡献共同归一化，预算不足时整组共享直线降级，不回退独立插值。新增 Swift 枚举值和 OC `stackedAreaUsesDivergingChains`，默认模式不变。详见 [完整契约与验证](charts-diverging-stacks-guide.md)。

**以下各历史章节仍说明 `.followBaseline` 的兼容规则与当时验证，不能用其准入/回退限制代替新模式的行为。**


历史更新（2026-09-29）修复了**可共享底边区间**的路径不重合问题，并明确了没有共同底边时的过渡规则。适用于折线图和混合图中的线族；不改变公开 Swift/Objective-C API、原始数据、数学堆叠、命中索引或百分比分母。

> 这不是“任意正负/缺测组合都能全域无缝”的承诺。保留原始堆叠点值及各系列缺测策略时，有些过渡区间并不存在唯一可共享的连续底边，详见末节。


## 2026-09-30：自动百分比共同归一化

本批将 `.followBaseline` 扩展到符合条件的自动百分比数学链。原来百分比始终使用兼容绘制：上层累计线独立插值、底边复用下层曲线，混合线型时仍会反填或重叠。最小复现 `[10,90,10] / [0.1,0.1,0.1] / [3,3,3]`，依次为曲线、直线、后置阶梯；修复前两条区域断言失败。

百分比必须作为**整条数学链**处理，不能把普通堆叠的厚度逐层直接相加，也不能将正、负两侧各自拉满 100%。当前采样点的分母仍是同链可见参与系列的原值绝对值总和；例如 `+60 / −40` 仍画在 `+60% / −40%`，不是 `+100% / −100%`。

采样点之间的新规则：

1. 各系列的采样百分比份额按自己的直线、曲线或阶梯插值，记为 `qᵢ(x)`；同链共同使用 `D(x) = Σ|qᵢ(x)|`。
2. 将 `100 × qᵢ(x) / D(x)` 分别累加到正、负链。符号变化处分片，阶梯跳变处共同切分；原始数据、百分比数值、零点归属和命中索引不改变。
3. 除法后的曲线通常不是普通三次贝塞尔。新增共同细分与控制点归一化，用共享三次曲线近似每条累计边界，几何误差目标 **0.05 pt**。同一分片的正、负外边界总跨度恒为 100%，各层厚度不反向、相邻层共享底边；不是最后再裁掉超过 100% 的部分。
4. 混合线型会**共同调整所有层**。例如上层的阶梯改变共享分母，下层曲线也可能同步跳变；无法同时保留所有独立曲线形状并要求每处总和为 100%。默认 `.independent` 保持原外观，普通/分组/固定基准模式仍使用原来的精确路径相加。

准入按同轴、stackID、数学图形族隔离：同链全部参与系列须为沿基线面积，具有一致的有效索引与缺测分段，且分母安全非零。同步缺测可以一起断开或一起连接；**非面积混用、分段不一致、原始或插值零分母、精度/细分预算不足时整链回退兼容绘制**，不让同链一部分归一化、一部分独立插值。非参与堆叠系列继续保持原值。

现有折线/混合页搜索 **百分比面积**，加载 **自动百分比面积对照场景**。20 个预设 / 400 组有序切换、258 个可编辑项是 9 月 30 日该批次的历史范围，不是当前面板总数。2026-10-02 已重新执行 8 项百分比单元测试和 1 项两页 UI，保存[实际补验日期的前后图、误差说明与验证](evidence/charts-legacy-comparison/2026-10-02-g1-percent/README.md)；未修改本节数学规则。当前 G2–G5 面板扩展后的 326 项 / 3,367 次绑定写入与 750 次渲染检查见[连续验证记录](charts-presentation-g2-g5-2026-10-02.md)。下方各旧批次中“自动百分比保持兼容”的描述属于当时范围。

## 2026-09-30：缺测底边分段与厚度过渡

本批处理上层跨较长缺测连接、下层中间断开的组合。此前只要下层在整段中有一次缺测，就将上层的整段底边退回直线，连两侧本来存在的曲线也丢失。最小复现：下层 `[10,90,NaN,10,70]`，上层 `[2,NaN,NaN,NaN,2]`，下层断开、上层连接。旧图在横坐标 `0.5 / 2 / 3.5` 均没有画出预期的上层薄带。

沿用 `.followBaseline`，现在先按前层真实连续段的起止索引细分：

- 仍有连续基线的子区间复用原来的曲线、阶梯及累计正负边界，不重算其切线。
- 无共同底边的真正缺口，按两端累计正/负基准分别直连；上层顶边由该基线加自身插值厚度生成，避免顶边继续独立插值而反向填充。上层自己跨零时，仍按厚度零点分片。
- 这条过渡只属于上层的绘制边界，下层面积仍按自己的缺测策略断开。不会补原始数据或命中样本，也不会擅自把下层改为 `connectAll`。
- 已绘制上层及已计算的正负累计边界可以继续被后层复用。中间系列有原始采样时，其累计基准仍约束边界；不能仅凭最外两端假定所有中间基准都相同。
- 查找更早基底时，补查后来系列在区间内部是否有贡献，避免两端缺测的中层把内部两个有效片段“藏掉”。

本批没有给缺测赋予业务值，也没有把直线过渡描述成已知数据。无唯一连续基线的缺口仍不承诺全域无重叠；例如下层连接跨空值、上层在该缺测索引却有有效点时，显示的下层插值与原始数学基准可能矛盾，不能同时保证保留原始点位和所有层处处贴合。自动百分比仍沿用兼容模式。

沿用已有 `theme.stackedAreaBoundaryMode = .followBaseline` / OC `stackedAreaFollowsBaseline = YES`，没有增加新的公共开关。当前系列切换符号时，如果正、负两条基线都能确定，就在**自身厚度的过零位置**把面积分别闭合到对应基线。两条基线之间使用描边子路径切换，不画穿过其它层的连接线。

## 2026-09-30：同符号薄层沿基线叠加（G1 第一批记录）

本批解决已复现的薄层反向填充：底层 `[10, 90, 10]` 为平滑曲线，上层 `[2, 2, 2]` 为直线。旧模式虽然精确复用了底边，但累计顶边独立插值后会穿入底层，橙色区域在下层内部出现，上方应有的薄层缺失。修复前同一用例有 2 条区域包含断言失败，已保存前后渲染图。

新增 `CartesianChartTheme.stackedAreaBoundaryMode`：

- `.independent`：默认，保留已有累计值独立插值及其外观，方便兼容和对照。
- `.followBaseline`：对同符号且具有共同源边界的区间，按当前系列连线方式插值自身厚度，再叠加到前层实际边界上。上边界、描边、后层引用使用同一份结果；阶梯保留垂直边，曲线在两条路径的节点并集处精确分段相加，不做折线采样近似。

这意味着上层会继承下层的曲线或阶梯形态：例如底层平滑、上层直线时，直线描述的是厚度的变化，最终上边界不再是一条独立直线。样本位置的 raw/base/draw、缺测位置、百分比分母和命中索引均不变，不添加可命中的中间点。

**适用范围**：普通堆叠、序号分组、固定基准百分比；正负链分别处理，五种连线方式可混用，连接上层缺测时保留下层中间节点。自动百分比 `percent` 继续使用独立插值，避免混合形态相加突破 ±100% 外包络；本批没有解决它的薄层组合问题。第一批时当前层跨零、源链切换或无共同底边的缺测区间保持原过渡；第二批仅补了上节可确定正负基线的跨零，不承诺全域无重叠。固定基准百分比本身允许超过 100%，不会钳制值域或厚度。

Swift（主线程通过 configure/update 应用）：

```swift
var theme = CartesianChartTheme()
theme.stackedAreaBoundaryMode = .followBaseline
chart.update(model: model, theme: theme)
```

Objective-C（主线程设置后重新配置/更新）：

```objc

[bridge updateWithModel:model preserveViewport:YES error:&error];
```

## 原因与修复

旧实现先给整段面积选择一种底边连接方式，再用该段基准点重建路径，存在两个问题：

1. **切线被重算**：即使全部基准点都来自同一前层，上层的缺测分段或跨空值连接也会截掉前层邻居点，改变单调曲线端点切线；看起来一样的点列，并不保证实际曲线重合。
2. **整段回退**：段内某处因正负或缺测切换基准来源时，整段退回当前系列的连接方式，连本来可以共享前层路径的区间也不再贴合。

现在每轮绘制为可见线族建立实际路径片段，描边、面积上边界和后续系列可共享底边使用同一组路径命令。缓存只存在于本轮绘制；数据、主题、显隐、视口或尺寸更新都会重新构造，避免旧控制点残留。

### 每个区间的规则

对于当前面积段中相邻有效索引 `i ... j`：

- 从后向前查找同一数学堆叠链的前层。跨值轴、跨 `stackID`、跨序号分组和跨柱/线族不会混用；隐藏或独立系列也不会错误串入。
- 前层在 `i`、`j` 的累计值必须与当前系列的堆叠基准吻合，且两个点属于前层同一个缺测段；所复用片段不能跨到相反符号链。
- 满足条件时，**倒序使用前层的原始路径命令**：三次贝塞尔控制点直接交换顺序，阶梯的水平/垂直边完整保留，不重新插值。
- 如果当前系列跨空值连接跳过了一些索引，底边仍保留前层在中间的实际顶点和曲线。
- 不满足条件时，只对这个区间使用**基准点之间的直线过渡**。不会跨越前层的断段去伪造平滑曲线，也不会让这次回退改变其它共享区间。

`normal`、`percent`、`percentFixed`、`grouped` 使用同一规则。零基准仍闭合到零轴。X/Y 颜色分区继续裁剪同一面积路径，不重新计算底边。

## Demo 操作

1. 首页进入 **折线图** 或 **混合图**，搜索 `接缝`。
2. 点击 **正负与缺测堆叠面积接缝场景**。场景会恢复默认配置，再加载三个系列、12 个点，启用普通堆叠和曲线面积。
3. 三条系列依次是“底层曲线”“正负与缺测”“上层缺测”；默认编辑第 2 号系列（从 0 开始）。中层有正负切换和缺测，上层另有一个缺测点。
4. 搜索 `系列连线覆盖`，分别尝试直线、平滑、三种阶梯；搜索 `跨空值连线`，比较上层断开与连接时的底边。
5. 要编辑前层，先搜索 `编辑系列序号` 切到 0 或 1；再修改其连线、可见性或数据覆盖。
6. 搜索 `堆叠` 切换普通、百分比、固定基准百分比；也可用图例隐藏前层，再显示回来。
7. 点击实际数据点检查原值、绘制值、堆叠基准。路径复用不会增加可命中的插值点。
8. 普通属性更新仍按“保留视口”设置处理；重新加载场景或恢复默认会重新开始。

场景属于现有页面，不增加新的同类图入口。全部登记项仍为 **226 个可编辑项**，预设/局部动作从 14 个增加为 **15 个**；有序场景隔离从 10×10 扩展为 **11×11 = 121 组**。

## 仍需明确的边界

**仍不支持任意缺测组合的连续堆叠曲面。** 当前系列自身跨零及已解析前层的符号切换已能复用正负连续边界。下层断段、缺少对应端点或不同缺测策略仍可能使某条基线无法确定；本批已把长区间细分，仅对真正缺口采用基准直线过渡并叠加自身厚度，保留数据点语义，不擅自修改累计值或补齐缺测。缺口无唯一连续基线的约束仍然存在。自动百分比现已对同链同缺测分段、分母安全非零的面积组合采用共同归一化；不满足准入条件的链仍兼容回退。

因此：

- 有共同前层路径的区间，本次保证复用实际几何；无共同路径的过渡区间，**仍不保证全域没有交叉、重叠或空隙**。
- 即使两端厚度为正，兼容模式的独立插值上下边界也可能在区间内部交叉；09-30 沿基线模式处理同符号共同区间、可解析跨零及其后续链切换，不对整个填充区域做布尔运算。
- 9 个位置的包含断言和保存的图片不是所有参数的像素级金图验证；尚未做真机、多系统、多尺寸或大规模性能验收。

若下一阶段要求“任意数据全域无缝”，需要先确定跨零和缺测时的连续堆叠语义，再处理交点、分段与填充布尔运算，不能只靠更换底边样式实现。
