# G1：正负分链、共享边界与统一断段

通用模型入口：先构造描述，再设置 `specification.schemaVersion = 2` 和 `specification.stackedAreaBoundary = .diverging`；旧 v1 保持 independent。详见[版本与边界契约](charts-neutral-model-guide.md)。原生 Swift/OC API 默认及本文几何实现不变。

更新：2026-10-02。实现入口为 `StackedAreaBoundaryMode.diverging`，适用于 Line 和 Combined 的**参与堆叠线族**。本模式是明确的新展示规则，不是修改原始数据，也不是将业务 series 拆成两个有新 ID 的 series。旧模式与默认外观保持兼容。

## 为什么不是简单地拆两份数据

数值堆叠原本就分别累计正、负值。接缝问题出在采样点之间：若累计顶边和底边各自插值，即使端点正确，薄层也可能穿进下层。将端点替换成 `max(value, 0)` 和 `min(value, 0)` 再独立插值，仍不能保留原曲线真正的过零位置。

新模式先构建各系列自身贡献曲线，合并所有系列的过零位置和阶梯跳变位置，再在共同分片上分别累计正、负边界。下一层直接复用上一层的边界控制点；跨符号链的面积分片各自闭合，描边不斜穿两条链。面积描边裁在本层内，原始 marker 仍独立绘制。

## Swift / Objective-C

```swift
var theme = CartesianChartTheme()
theme.stackedAreaBoundaryMode = .diverging
// 原 model 的 series、ID、正负数、NaN、stacking 保持原样。
chart.update(theme: theme)
```

```objc
bridge.stackedAreaUsesDivergingChains = YES;
[bridge updateWithModel:model preserveViewport:YES error:&error];
```

OC 新开关默认 `NO`；优先级高于 `stackedAreaFollowsBaseline`。将新开关关闭后，根据旧开关恢复沿基线或独立插值。Swift 默认仍是 `.independent`。

## 明确的展示契约

| 项目 | 新模式的规则 |
|---|---|
| 数学分组 | 按值轴、stackID、图形族和 grouped 序号分区隔离；不把柱族的缺测传播到线族 |
| 正负贡献 | 每个共享区间内独立累积；真正过零后切换链，不重写数据符号 |
| 支持线型 | 直线、单调平滑、前置/后置/居中阶梯，可同组混用；累计表面会继承其他贡献的拐点 |
| 非面积折线 | 只要参与同组堆叠，也贡献基线/百分比分母；不要求同组每个系列都填充面积 |
| 缺测 | 同组任一可见参与系列在该索引缺测、非有限或短尾，**全组在此断开**；空数组也不是自动补零 |
| 策略优先级 | 统一断段优先于每系列 connectNulls / gapPolicy / autoGap；不删除这些配置，切回旧模式恢复 |
| 隐藏/独立系列 | 隐藏或 participatesInStack=false 的系列不使其他组断开；显隐变化重新生成几何 |
| marker / 命中 | 保留该系列自身有效原始点、ID、索引及 raw/base/draw；共同缺口中仍可能有可命中的原始点 |
| 零值 | 普通数学采样的零值仍属正链；不为几何过零生成业务采样、marker 或 tooltip 行 |
| 普通 / grouped | 贡献曲线精确相加，不做自动百分比归一化 |
| percentFixed | 使用既有固定分母后的贡献曲线；不保证组总跨度为 100% |
| percent | 使用下面的共同原始贡献归一化规则 |
| 自动值域 | 包含各区间贡献端点范围之和的保守包络，避免混合阶梯的区间峰值被裁掉；百分比按存在的符号侧扩展到 ±100；显式 min/max 和用户 Y 视口仍优先 |

统一断段有意牺牲“上层跨空连线、下层保持缺口”这种相互冲突的连续性要求。不能同时承诺每系列独立的连线规则、所有原始累计点位和处处连续贴合；选择本模式即选择清晰的共同缺口。有效点的原始数值和交互不受影响。

## 自动百分比：同一分母，不能正负各拉满 100%

1. 在共同有效段中，按各系列配置插值**原始贡献** `fᵢ(x)`，而不是先把采样点百分比插值。
2. 分母 `D(x) = Σ |fᵢ(x)|`；份额为 `100 × fᵢ(x) / D(x)`，再分别累计正负链。例如 `+60 / -40` 为 `+60% / -40%`，而不是两侧各 100%。
3. 共享三次曲线逼近归一化后的有理曲线，每条累计边界的误差目标为 **0.05 屏幕 pt**。各层使用同一细分网格/分母，正负外包络总跨度保持 100%（浮点精度内）。缩放/布局改变后重新评估屏幕误差。
4. 原始采样点分母为零或被现有数值保护判为不可用时，全组断开。不补值、不把不确定比例伪装成零。若所有贡献在某个**区间内部同一过零点**同时为零，约去共有零因子、使用各自单侧比例极限；正负两侧可不连续，不跨链斜连。若整个区间贡献恒为零，则没有面积或桥接描边。
5. 细分预算（每组 16,384 片）或深度/数值条件不能满足曲线要求时，**整组原子性降级**：从共同直线贡献网格上的归一化端点构造共享直线边界，保留符号、100% 外包络和原始采样，但不再承诺原曲线形态或 0.05 pt 的曲线逼近误差。绝不静默退回独立累计边界，也不只降级某一层。
6. `LineChartRenderer.divergingBoundarySeries` / `divergingLinearFallbackSeries` 提供最近一次绘制的系列索引集合（主线程读取，下一次重画刷新）。Demo 直接显示 renderer 的结果，不按开关值猜测。

与 `.followBaseline` 的重要区别：沿基线模式保留既有缺测策略，百分比插值的是**采样份额**，并有整链准入/兼容回退。这里使用**原始贡献插值后归一化**和统一断段；两种模式的采样点间外观不同是有意的，采样点数值和命中数据相同。

## 测试与验收边界

专项覆盖：普通与自动百分比各 125 种三层线型组合、真实过零、共享控制点相等、稀薄负贡献、原始百分比插值、同时归零、整段零分母、强制预算耗尽、缺测/短尾/空数组、不同轴/stackID/grouped/图形族隔离、非面积贡献、Line/Combined/OC 一致性、原值命中、复用开关、显隐、尺寸/视口与模式切换、混合阶梯的区间峰值与双轴显式范围、诊断实际发布/清理、五种线型 × 两种线宽 × 1×/2×/3× 描边像素范围检查、1,500 点 × 6 系列输入。

测试与图像证据见 [2026-10-02 G1 正负分链验证](evidence/charts-legacy-comparison/2026-10-02-g1-diverging/README.md)。G1 此展示契约范围的完善不等于旧模式强制换外观，也不等于所有硬件、输入规模或整个老项目迁移已经验收。

- 共享数学边界不承诺所有系统/缩放下半透明渐变的逐像素栅格结果完全一致；真实设备的抗锯齿、超薄层可见性仍需实际项目验收。
- 数值仍要求落在现有坐标轴可表示范围内；不扩展 Double 溢出、无限输入或不受限点数的支持契约。
- 不变更业务数据结构、不增加新页面、不扩张 G6 输入模型，不处理正式旧项目调用适配及外围 UIView。
