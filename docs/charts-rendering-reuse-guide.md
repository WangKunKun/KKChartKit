# 绘制图层与标签复用

适用：Line / Column / Bar。默认开启，配置在共用主题中：

```swift
var theme = CartesianChartTheme()
theme.reusesRenderingObjects = true
chart.update(theme: theme) // 在主线程应用；默认保留视口
```

## 复用范围

- 坐标轴与网格线、标题和刻度 UILabel。
- 标线、色带及其文字。
- 折线、marker、空心点、面积渐变与 mask。
- 柱体/条形复合路径、堆叠分隔线、阴影投射层。
- 系列数据标签与堆叠总量标签；Column / Bar 入场动画的逐帧绘制也复用。

渲染器分别管理公共装饰对象和系列对象，避免系列动画消耗坐标轴的复用槽位。按类型、绘制顺序领取对象，覆盖几何和样式；对象身份不参与系列 ID、图例或命中判断。形状切换时恢复填充、描边、虚线、阴影、strokeEnd 等状态；旋转刻度复位 transform，渐变先解除旧 mask。

每帧结束释放未使用对象，缩放或隐藏系列后不会一直保留之前的对象峰值。卸载时清理对象池；空数据同样进入系列清理流程，避免旧图形与命中缓存残留。

这一步减少的是 UIKit / Core Animation 对象的重复创建。路径与坐标仍随布局重算，图层仍按既定顺序重新挂载；尚未实现几何缓存、局部失效或持久图层树。图例、tooltip、Radar / Heatmap 的内部对象不在本次复用范围内。

## Demo 对照

进入首页的折线、柱状或条形图，在属性搜索输入 `reusesRenderingObjects`，切换“复用图层与标签”。它直接绑定主题，默认开启；关闭后仍执行相同布局与绘制，用于视觉和分配开销对照。高密度场景继续使用原页面的 3000 点预设、总览与明细按钮。

对象复用与 Min/Max 降采样、Column 时间聚合独立；关闭复用不会关闭聚合或改变原始数据、命中值、图例配置及视口策略。

## 验证边界

`RenderingReuseTests` 验证实际对象身份复用、开关绑定、空数据恢复、旋转复位、样式切换后的图片对照、密集到稀疏的释放，以及动画标签/阴影不累积。界面测试在三个统一 Demo 页面切换真实开关。

性能用例记录 3000 点、2 系列、预热后 12 次同尺寸 layout 的同步 CPU 耗时和池内对象创建/复用数。对象统计只包含上面的复用范围，不能解释为全 App 零分配。Debug 模拟器数据不代表真机触控 FPS、GPU 呈现耗时或峰值内存；真机 Instruments 验证仍待完成。


最终验证：107 项单元测试、4 项界面测试通过（本步新增 8 项单元测试、1 项界面测试）。对象释放测试在提交 CA 事务并退出 autoreleasepool 后验证弱引用失效；样式对照逐步更新同一图表，再与关闭复用的图表做 PNG 比较。

[原始 CSV](benchmarks/2026-09-24-render-object-reuse-simulator.csv)：Xcode 26.3 / iPhone 17 / iOS 26.3 Simulator / Debug，单次观测。

| 3000 点 × 2 系列 | 关闭复用，平均布局 | 开启复用，平均布局 | 12 帧池内创建数：关 → 开 |
|---|---:|---:|---:|
| 原始点与 marker | 26.94 ms | 25.28 ms | 72,252 → 0 |
| Min/Max，密集时隐藏 marker | 14.67 ms | 13.74 ms | 252 → 0 |

这是重复布局的对象分配对照，不是首绘、真实拖动或总内存基准。测量包含数据准备、几何与 path 构建；复用不会消除这些开销。下一步应对几何/刻度计算和局部更新继续分项测量。
