# 图表统一调试页面

2026-10-03：折线/柱状/条形/混合页右上角新增“通用模型”，在同一页面切换到 [ChartSpecification 适配预览](charts-neutral-model-guide.md#demo-与验证)。可调缺测、百分比、图例、面积与插值，另有真实数值 X/反向轴的不支持诊断；全部走真实适配器。返回“原生属性”保留原面板配置，但重新创建图表，不保留此前手势窗口/选中状态。该入口未增加首页同类页面，也未将中立模型字段计入原生主题绑定数量。

首页每类图表只有一个入口：雷达、热力、折线、柱状、条形、混合。Objective-C 接入示例单独保留，属于语言互操作示例。

每页上方固定预览、下方为可搜索的折叠属性分组。预览高度可调，最多占可用页面的 60%，其余空间留给面板。颜色支持透明度；可选值可以关闭以恢复默认；恢复默认同时重置数据、样式、视口和交互状态。

图例已并入四种轴系图的面板。图例标题/颜色/符号覆盖位于“当前系列”，布局参数位于“图例布局”。“测量并追加图例高度”调用 `ChartLegendMeasurer.measure`，实时显示完整内容尺寸与预留高度；高度上限仍保护面板可见空间。

“当前系列”采用稳定 ID 保存各系列配置；隐藏再显示、减少再增加系列数时不会串样式。数据覆盖接受逗号分隔数值，`nan` 或空项表示缺测；清空后恢复生成数据。闭包不能在面板中编辑任意 Swift 代码：聚合、格式化、自定义弹窗均为明确命名的可执行预设，SDK 仍接受业务自己的闭包。

时间轴默认将一天均分为实际最长系列的点数（包括手动数据覆盖），288 点才是 5 分钟间隔；关闭均分可自定义秒间隔。主/次轴绑定在系列设置中选择。Bar 的缩放轴表示屏幕方向，类目沿 Y、数值沿 X。

## 后续新增功能的同步要求

每个新增或修改的可配置功能，必须同一变更同步：

1. 对应图表页的属性面板，包括默认/关闭、自定义与依赖条件。
2. 模型或主题的真实 Binding，避免展示了控件却被其他状态覆盖。
3. 至少一个可复现样例或测试；涉及渲染/布局时检查模拟器结果。
4. 对应使用指南以及本页覆盖说明。

公共主题基础字段集中登记在 `DemoThemeFields.swift`；轴系面板由 `CartesianDemoState.swift`（状态/预设）、`CartesianDemoControls.swift`（Binding 登记）、`CartesianDemoRules.swift`（依赖/覆盖提示）与 `CartesianDemoSettings.swift` 组成，页面布局位于 `CartesianChartDemo.swift`。雷达和热力保持各自 Demo。不要为新功能另建同种图表的独立 Demo 页面。尚未实现的 SDK 能力不放置无效开关。

自定义弹窗、位置回调与内置弹窗是互斥预设。命中读数独立观察，更新读数不会重配图表，从而保留刚显示的选中态。

验证记录：六类页面逐页搜索并切换属性；3000 点预设、总览/局部明细与恢复默认通过界面测试；绑定、独立系列 reducer 与热力 SwiftUI 主题透传通过单元测试。完整验证结果见 [能力状态](charts-capability-status.md)。

折线图的“高密度折线 Min/Max”分组支持宽度模式和目标点数模式。要精确保留数量，使用“3000 点目标点数采样场景”，编辑“每系列目标绘制点数”并应用；目标模式会禁用宽度/启动门槛并显示实际数量，缺测端点/极值保护可能超额。详见 [降采样指南](charts-line-sampling-guide.md)。

折线/柱状/条形共用主题新增 `reusesRenderingObjects`（默认开启），搜索属性名可实时切换图层与标签复用；见 [复用指南](charts-rendering-reuse-guide.md)。

柱状与条形图新增 `columnSpacing` 固定尺寸控件、60 点滚动预设和自定义区间索引定位；默认展示最早数据。详见 [固定布局指南](charts-fixed-column-layout-guide.md)。

迁移第 1 步：三个轴系页增加“数据语义：100 + 50 堆叠”预设、业务组 ID/名称与每系列格式；命中读数显示原值/绘制值/起点/占比。Objective-C 接入 → 轴系验证可切换三种图验证 OC 回调。详见 [数据语义指南](charts-data-semantics-guide.md)。


迁移第 2 步增加了“混合图”唯一入口：共用轴系面板，并同时展示柱体和折线外观字段。逐系列可修改 kind、stackID、participatesInStack、线宽/连接、标记显隐/半径、面积开关/渐变/透明度，覆盖可恢复默认。其他轴系页同步适用配置；搜索“两组堆叠”加载示例，混合图额外显示右轴目标曲线。`grouped(groupCount:)` 对应“序号分组”及组数量。OC 验证页面有第四种“混合”类型。见 [使用指南](charts-combined-and-stacks-guide.md)。


迁移第 3 阶段的缺测子项：折线/混合图的“当前系列”新增“缺测策略 autoGap”，可选择全部断开、全部连接、空点数上限、时长上限或恢复 `connectNulls`；只有适用模式显示对应参数。搜索 autoGap 可加载“11/12/13 空点 autoGap 场景”，搜索“缺测”可调整上限。时长策略要求开启有效时间轴；默认预设关闭一天均分并设为 300 秒/点。见 [缺测策略指南](charts-gap-policy-guide.md)。

### 跨零正负基线面积对照（2026-09-30）

现有折线图/混合图搜索“跨零正负”，加载三系列对照场景。开启既有“沿基线叠加”模式时，在自身厚度过零点拆开正负面积，分别闭合到可确定的正、负基线上；切回“独立插值”查看原来的斜穿效果。原始零值仍属正链；基线无法确认时保留相应过渡；自动百分比使用下方共同归一化准入规则。可继续编辑当前系列连线、显隐与堆叠类型。详见[跨零分片规则](charts-stacked-area-seams-guide.md)。

描边补修：沿基线模式下，描边也收在各自面积内，交界处及左右端点不会因圆帽/线宽而外凸。预设默认仍显示真实采样标记；搜索 `showsPoints` 关闭后，可单独检查面积接缝，再开启核对原始点位置。“当前状态”有对应说明，测试同时保存两种显示状态。[同输入补修图片](evidence/charts-legacy-comparison/2026-09-30-g1-stroke/README.md)。
