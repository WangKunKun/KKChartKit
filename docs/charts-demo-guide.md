# 图表统一调试页面

首页每类图表只有一个入口：雷达、热力、折线、柱状、条形。Objective-C 接入示例单独保留，属于语言互操作示例。

每页上方固定预览、下方为可搜索的折叠属性分组。预览高度可调，最多占可用页面的 60%，其余空间留给面板。颜色支持透明度；可选值可以关闭以恢复默认；恢复默认同时重置数据、样式、视口和交互状态。

## 面板覆盖

| 页面 | 可调内容 |
| --- | --- |
| 雷达图 | 维度数量、逐维度名称/数值/满分/字体/颜色/标题点覆盖、中心分数、全部主题字段、网格填充预设、线型与虚线参数、装饰环、选中态、弹窗外观与回调预设 |
| 热力图 | 行列数、锯齿行、行列标签、色阶值域、逐格值/有效性/颜色/提示、全部主题字段、渐变/透明度/分段色阶及锚点、对齐、弹窗 |
| 折线图 | 数据、逐系列样式与显隐、堆叠、双轴、时间轴、线型/标记/空值连接、面积渐变、网格/坐标/标签/背景、图例、阈值线/色带、交互、弹窗、Min/Max 开关/分组宽度/启用门槛/密集标记及标签策略、尖峰预设与明细 |
| 柱状图 | 以上通用轴系能力，以及柱体/分隔线/总量标签、288/1440/3000 点预设、每系列聚合规则、最小柱宽、首选聚合区间、缓存开关、粒度切换缓冲、总览/最近24点/所选区间 |
| 条形图 | 通用轴系能力与柱体样式、堆叠、总量标签、逐条颜色、图例、交互；值轴仅支持主轴，无时间聚合 |

图例已并入三种轴系图的面板。图例标题/颜色/符号覆盖位于“当前系列”，布局参数位于“图例布局”。“测量并追加图例高度”调用 `ChartLegendMeasurer.measure`，实时显示完整内容尺寸与预留高度；高度上限仍保护面板可见空间。

“当前系列”采用稳定 ID 保存各系列配置；隐藏再显示、减少再增加系列数时不会串样式。数据覆盖接受逗号分隔数值，`nan` 或空项表示缺测；清空后恢复生成数据。闭包不能在面板中编辑任意 Swift 代码：聚合、格式化、自定义弹窗均为明确命名的可执行预设，SDK 仍接受业务自己的闭包。

时间轴默认将一天均分为指定点数，288 点才是 5 分钟间隔；关闭均分可自定义秒间隔。主/次轴绑定在系列设置中选择。Bar 的缩放轴表示屏幕方向，类目沿 Y、数值沿 X。

## 后续新增功能的同步要求

每个新增或修改的可配置功能，必须同一变更同步：

1. 对应图表页的属性面板，包括默认/关闭、自定义与依赖条件。
2. 模型或主题的真实 Binding，避免展示了控件却被其他状态覆盖。
3. 至少一个可复现样例或测试；涉及渲染/布局时检查模拟器结果。
4. 对应使用指南以及本页覆盖说明。

公共主题基础字段集中登记在 `DemoThemeFields.swift`；复杂配置在 `CartesianDemoSettings.swift`、`CartesianChartDemo.swift`、雷达和热力各自 Demo。不要为新功能另建同种图表的独立 Demo 页面。尚未实现的 SDK 能力不放置无效开关。

自定义弹窗、位置回调与内置弹窗是互斥预设。命中读数独立观察，更新读数不会重配图表，从而保留刚显示的选中态。

验证记录：五类页面逐页搜索并切换属性；3000 点预设、总览/局部明细与恢复默认通过界面测试；绑定、独立系列 reducer 与热力 SwiftUI 主题透传通过单元测试。完整验证结果见 [能力状态](charts-capability-status.md)。

折线图新增的 Min/Max 功能已同步到“高密度折线 Min/Max”分组；详见 [降采样指南](charts-line-sampling-guide.md)。
