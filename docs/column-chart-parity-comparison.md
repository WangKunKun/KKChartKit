# 柱状图／条形图：当前展现能力与缺口

更新：2026-10-02。按用户要求聚焦图表本体，以下基于当前本地源码；旧版三方表中的“独有/领先”、将 Highcharts 正负堆叠统一称为错误等结论不再作为依据。已运行的新旧引擎差异见[对照报告](charts-legacy-demo-parity-results.md)，当前顺序统一采用[实施计划 G 队列](charts-legacy-replacement-plan.md#4-当前绘制队列与后续迁移队列)。

## 已有能力

| 形态/内容 | 当前实现 | 边界 |
| --- | --- | --- |
| 垂直柱、水平条、并排分组 | Column/Bar 共用模型、布局和数学语义 | Bar 类目在屏幕 Y 方向，值轴在 X 方向 |
| 普通/正负/百分比/固定基准堆叠 | 原值、累计位置、基线和百分比分开；正负分别累计 | percent 按同栈绝对值总和归一，不表示正负各自都到 100%；percentFixed 按固定分母 |
| 多栈、双轴、混合图柱系列 | stackID、值轴、柱/线族分链；Combined 可混合线与面积 | Column/Combined 支持双值轴；Bar 当前只支持主值轴 |
| 宽度与间距 | 比例布局、固定柱宽/间距、组内/组间距 | 固定宽度的窗口/滚动须按实际容器宽度验收 |
| 圆角、边框、小值最小柱高/条长 | 已有主题配置；堆叠圆角按可见链端处理 | minPointLength 不给堆叠小段凭空增加数值高度 |
| 系列色、逐柱/条色、负值颜色、阴影、阈值分区 | 已实现，G2 补齐 | 有效 zones 优先；无/非法 zones 回退 negativeColor → barColors → 系列色；nil 分区色及尾段回退系列基础色 |
| 数据标签、堆叠总量标签 | formatter、系列覆盖、数量限制、链端正负总量、背景与可选避让 | 先避开标注，再总量优先；确定性省略碰撞标签，不做全局最优排布 |
| 标线、色带、类目标签旋转 | 独立文字样式、对齐、偏移与边界策略；支持相应值轴绑定 | 标注间不自动排布；旋转仅垂直图底部类目标签 |
| 命中、准线、提示、主体高亮、图例显隐、缩放与更新 | 已有公共能力与回归；G5 高亮默认关闭 | 单点/共享覆盖层；更新、目标隐藏、重播和取消时清理，不提供跨更新选点恢复 |
| 高密度时间聚合 | Column 有原始源范围与聚合数据分离 | Bar 和 Combined 不因此视为支持同样聚合 |

源码入口：[Column](../SwiftFunctionProject/Charts/Column/ColumnChartRenderer.swift)、[Bar](../SwiftFunctionProject/Charts/Bar/BarChartRenderer.swift)、[数据模型](../SwiftFunctionProject/Charts/Cartesian/CartesianChartModel.swift)、[主题](../SwiftFunctionProject/Charts/Cartesian/CartesianChartTheme.swift)。

## G2–G5 已交付及仍保留的候选缺口

| 缺口 | 核查结果 | 当前安排 |
| --- | --- | --- |
| 柱/条阈值着色 | 已由 Column/Bar/Combined 实际消费；Y raw/draw、X 原始索引 | G2 已交付整段选色；柱内按高度裁成多个色段仍是另一能力 |
| 独立轴样式/显隐、类目间隔 | 各轴独立覆盖颜色/字体/轴线，关闭标签取消相应预算；显式间隔保留自动防密 | G3 已交付；不保证小屏下强制画满所有候选标签 |
| 标线/色带标签样式、数据标签可读性 | 独立样式、背景、对齐/偏移、clamp/hide；可选数据/总量避让 | G4 已交付确定性基础；标注文字之间不自动排布 |
| 点/柱/条主体选中高亮 | 共用 applySelection 显示点环/实际柱条覆盖层，Combined 协调图形族 | G5 已交付；不提供整条线高亮、跨页面选择状态 |
| 反向轴、轴域比例留白 | 尚无完整通用配置 | G6 候选，需让几何、网格、零轴与命中使用同一坐标变换 |
| 范围柱/悬浮柱、瀑布形态 | 目前 series 输入是一维值，不能把圆角或堆叠当成完整范围数据模型 | G6 候选，先区分起终值范围、胶囊外观与累计增减三种语义 |
| 柱体任意渐变、数据标签边框/旋转 | 当前配置不完整；数据/总量标签背景已在 G4 提供 | 后续图表样式增强，分别确定系列/逐点优先级 |
| 对数轴、超过两根值轴、极坐标 | 无通用实现 | 不自动扩入首批，避免分散当前轴系图表完善工作 |

这些是绘制能力缺口，不以先完成业务卡片或旧 API facade 为前提。新能力在现有柱状、条形及混合图 Demo 中加入配置/命名场景；保持每种图表一个页面。

## G2 验收重点

- 明确按 raw 还是 draw 选颜色，以及阈值相等时归属哪段；普通、堆叠、百分比不能含糊混用。
- 有效 zones、无效配置、negativeColor、barColors 和默认系列色有明确优先级；没有新配置时保留原行为。
- 测试正负、零、缺测、短系列、隐藏/恢复、主次轴、Column/Bar 方向以及 Combined 柱系列。
- 颜色变化不改变柱槽、几何尺寸、堆叠基线、业务原值和命中身份。
- 保存真实渲染与边界断言，不能仅以配置对象包含 zones 字段判定功能完成。
